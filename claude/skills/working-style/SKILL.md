# Working style

## Messages the user will send

The user copies these out of the terminal and mostly pastes them into Slack, so write them
ready to paste:

- Plain text: short paragraphs, numbered or bulleted lists, **bold** only where it helps.
- Never put the message in a `>` blockquote. Copied from the terminal, every line then starts
  with a `|` bar.
- One short lead-in line ("Here's a message for …:"), then the message itself, with nothing
  around it that has to be cut out.
